# Chaos measurement: mock (2026-11-03 11:18 KST)

## Command and environment

- Command: `python scripts/chaos_demo.py --base-url http://127.0.0.1:8040`
- Server: `EM_PROVIDER=mock`, `EM_DEMO_CHAOS=1`; API version 0.1.0
- Target: `all`; modes: error, hang; 6 requests per mode under chaos, plus warm-up and recovery; POST /api/triage, one fixed query and point
- Breaker: opens after 3 consecutive failures, HALF_OPEN after 30 s
- Client: Python 3.14.6 on Linux x86_64

fallback_ms runs from the moment the tool call failed (or the open circuit skipped it) to the cached
data being served; the failed call itself is RT-102 time.
